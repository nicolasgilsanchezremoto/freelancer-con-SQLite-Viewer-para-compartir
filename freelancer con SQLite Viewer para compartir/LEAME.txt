Estimado Instructor,

A continuación comparto los pasos para la ejecución local de la aplicación
web y la verificación del almacenamiento de datos en la base de datos SQLite.

------------------------------------------------------------------------
1. REQUISITOS PREVIOS
------------------------------------------------------------------------
- Tener instalado Node.js (v14 o superior).
- Visual Studio Code (Recomendado).
- Extensión de VS Code recomendada: "SQLite Viewer" (para explorar la 
  base de datos 'contactos.db' directamente dentro del editor).

------------------------------------------------------------------------
2. INSTALACIÓN DE DEPENDENCIAS
------------------------------------------------------------------------
1. Abra la consola de comandos (CMD o Terminal de VS Code).
2. Navegue hasta la carpeta del backend ejecutando:
   
   cd backend

3. Ejecute el siguiente comando para instalar los paquetes necesarios
   (express, sqlite3, cors):

   npm install

------------------------------------------------------------------------
3. INICIAR EL SERVIDOR (BACKEND)
------------------------------------------------------------------------
Dentro de la carpeta 'backend', ejecute el comando:

   node server.js

Verá en consola los siguientes mensajes de confirmación:
  -> Base de datos SQLite conectada correctamente.
  -> Servidor escuchando en http://localhost:3000

------------------------------------------------------------------------
4. PROBAR LA APLICACIÓN (FRONTEND Y PERSISTENCIA)
------------------------------------------------------------------------
1. Abra la carpeta 'freelancer_fin' y abra el archivo 'index.html' en 
   su navegador (haciendo doble clic o mediante Live Server).
2. Navegue a la sección "Contacto", complete el formulario con los campos:
   - Nombre
   - Teléfono
   - Correo
   - Mensaje
3. Haga clic en el botón "Enviar". Aparecerá una alerta informando:
   "¡Mensaje enviado con éxito!".

------------------------------------------------------------------------
5. VERIFICACIÓN DE LOS DATOS EN LA BASE DE DATOS
------------------------------------------------------------------------
Opción A (Mediante la Extensión SQLite Viewer en VS Code):
- Abra la carpeta 'backend' en VS Code.
- Haga clic sobre el archivo 'contactos.db'.
- Se abrirá la vista con la tabla 'mensajes' donde podrá observar los 
  registros guardados con sus campos: id, nombre, telefono, correo, 
  mensaje y fecha.

Opción B (Mediante la API GET):
- Con el servidor corriendo, ingrese desde su navegador a:
  http://localhost:3000/api/contacto
- Obtendrá un JSON con la lista de todos los mensajes registrados.
